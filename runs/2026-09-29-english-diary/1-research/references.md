# 레퍼런스 — 영어가 내 것이 되는 일기

## 리서치 기준

- 무드 방향: 공부 앱보다는 나만 보는 차분한 기록장에 가깝게 합니다. 성취는 점수나 연출이 아니라 날짜와 내 문장 같은 사실로 담백하게 보여 주고, 쉬었다 돌아와도 압박이 없는 화면을 지향합니다.
- 무드 태그 목록: 차분함 · 개인 기록 · 사실 중심 · 담백함

## 레퍼런스

### R1. 하이링구얼 — 메인 / 일기 작성 전

- 링크: https://uibowl.io/name/%ED%95%98%EC%9D%B4%EB%A7%81%EA%B5%AC%EC%96%BC?patterns=%EB%A9%94%EC%9D%B8&patternName=%EC%9D%BC%EA%B8%B0%20%EC%9E%91%EC%84%B1%20%EC%A0%84
- 대응 화면: Home
- 무드: 개인 기록
- 가져올 것: 날짜 아래에 '오늘의 추천 주제' 카드(영어 질문 1개와 교체 아이콘)가 있고, 그 아래 폭 전체를 쓰는 '일기 작성하기' 주 버튼 하나가 있습니다. 오늘 할 일이 하나로 모이는 구조입니다.
- 피할 것: 프로필 아래 '0일 연속 작성 중'(불꽃 아이콘)과 '45시간 남았어요' 카운트다운이 있습니다. 스트릭·공백·독촉에 해당하므로 금지입니다(PRD 6.3, 7). 상단을 차지하는 월간 캘린더도 빈칸이 공백 일수로 읽히기 쉬워 Home 첫 화면에서는 피합니다(PRD 6.3).

### R2. 하이링구얼 — 글쓰기 (일기 작성하기)

- 링크: https://uibowl.io/name/%ED%95%98%EC%9D%B4%EB%A7%81%EA%B5%AC%EC%96%BC?patterns=%EA%B8%80%EC%93%B0%EA%B8%B0
- 대응 화면: Write
- 무드: 담백함
- 가져올 것: 위에서부터 날짜, 오른쪽 위 '텍스트 스캔하기'(OCR) 버튼, 접히는 '오늘의 추천 주제 참고하기', 영어 placeholder("What's been going on today?")가 든 큰 입력 영역, 글자 수, 사진 첨부 칸, 하단 고정 CTA 순서입니다. 입력 영역이 화면 대부분을 차지하고 OCR과 사진이 같은 화면에서 보조 진입점 역할을 합니다.
- 피할 것: 비활성 CTA 위에 '10자 이상 작성해야 피드백 요청이 가능해요' 툴팁을 띄우는 차단형 안내입니다. 잘못한 것처럼 느끼게 하므로 피합니다. 추천 주제가 모범 문장 형태로 바뀌면 대필이 되므로 질문 형태만 허용합니다(PRD 6.5).

### R3. 하이링구얼 — AI / 피드백 상세 (일기장)

- 링크: https://uibowl.io/name/%ED%95%98%EC%9D%B4%EB%A7%81%EA%B5%AC%EC%96%BC?patterns=AI&patternName=%ED%94%BC%EB%93%9C%EB%B0%B1%20%EC%83%81%EC%84%B8
- 대응 화면: Review
- 무드: 사실 중심
- 가져올 것: '문법·철자 / 추천표현' 탭으로 교정 종류를 나눕니다. 사진과 일기 본문을 한 카드에 함께 둡니다. 아래 '주요 피드백' 영역은 사용자 원문을 'me' 라벨 행으로 다시 보여 주고 그 아래에 제안을 붙입니다. 내 표현에서 시작하는 수정 단위 구조입니다.
- 피할 것: '교정된 일기' 토글은 본문 전체를 교정본으로 바꿔 보여 줍니다. 자동 Rewrite나 원문 대체로 읽히므로 피합니다(PRD 6.1, 7). 수정 부분을 주황 글자색으로만 표시하는 방식도 피합니다(design-base 2·5, 색만으로 의미 전달 금지). 하단 '피드에 게시하기' CTA는 공개 피드에 해당해 금지입니다(PRD 7).

### R4. 하이링구얼 — 검색 / 나의 단어장

- 링크: https://uibowl.io/name/%ED%95%98%EC%9D%B4%EB%A7%81%EA%B5%AC%EC%96%BC?patterns=%EA%B2%80%EC%83%89&patternName=%EB%82%98%EC%9D%98%20%EB%8B%A8%EC%96%B4%EC%9E%A5
- 대응 화면: My English (저장한 표현)
- 무드: 담백함
- 가져올 것: 상단 검색 바, '최신순' 정렬, '오늘' 같은 날짜 그룹 헤더, 표현마다 한 장씩인 카드(품사·숙어 태그 + 구 단위 표현 + 북마크)입니다. 구 단위 표현(catch up with 등)을 한 줄 카드로 쌓는 단순한 구조를 가져옵니다.
- 피할 것: 표현만 나열하고 처음 쓴 일기, 회상, 스스로 씀으로 이어지는 흐름이 없습니다. 이대로면 단어장에 그치므로 Expression Journey 진입이 필요합니다(PRD 5 My English, 8).

### R5. 하이링구얼 — 기타 / 로딩 (일기 저장 중)

- 링크: https://uibowl.io/name/%ED%95%98%EC%9D%B4%EB%A7%81%EA%B5%AC%EC%96%BC?patterns=%EA%B8%B0%ED%83%80&patternName=%EB%A1%9C%EB%94%A9

- 피할 것: 하단 '지금 화면을 나가면, 작성 중인 일기가 저장되지 않아요' 경고는 Write 자동 저장 요구와 충돌합니다(PRD 5 Write). 화면 중앙의 캐릭터 일러스트도 피합니다(PRD 7 캐릭터 중심 금지).

### R6. 하루냥 — AI / 일기작성

- 링크: https://uibowl.io/name/%ED%95%98%EB%A3%A8%EB%83%A5?patterns=AI&patternName=%EC%9D%BC%EA%B8%B0%EC%9E%91%EC%84%B1

## 반영 요소

### RP-1. Home에는 주 행동 '오늘 기록하기' 하나만 둡니다. 누르면 입력 소스(사진 / 대화 캡처 / 텍스트 스캔 / 바로 쓰기)를 텍스트 라벨과 아이콘 쌍으로 펼쳐 고르게 합니다.

- 근거 레퍼런스: R1, R9, R2
- PRD 연결: 5 MVP 화면 — Home(기록 시작 시 사진 / 대화 캡처 / OCR / 바로 쓰기 중 선택), 3 MY LIFE

### RP-2. Write 상단에는 사진·기록에서 나온 질문 하나와 '다른 질문' 교체만 둡니다. 질문은 경험을 떠올리게 하는 prompt일 뿐이고 예문이나 모범 문장은 넣지 않습니다.
