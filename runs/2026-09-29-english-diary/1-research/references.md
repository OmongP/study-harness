# 레퍼런스 — 영어가 내 것이 되는 일기

> 출처 상태: 2026-09-29 UIbowl 검색 실패(503 오류 1회 후 일일 무료 한도 10/10 소진). 아래 레퍼런스는 UIbowl 화면으로 확인하지 않았고, 공개된 앱 화면에 대한 일반 지식으로 작성했음. 링크는 모두 미확인이며, 한도가 풀리면 UIbowl 실제 화면으로 교체·확인이 필요함 (사람 확인 항목).

## 리서치 기준

- 무드 방향: 매일 쓰지 않아도 편하게 돌아올 수 있는 성인용 개인 기록 노트. 여백이 넉넉하고 과장이 없으며, 성장을 점수 대신 날짜와 사실로 조용히 보여주는 담백한 도구 (PRD 6.3·6.4·7).
- 무드 태그 목록: 담백 · 차분함 · 개인적 · 신뢰

## 레퍼런스

<!-- 링크는 출처 확인용 선택 항목이다. 비어 있어도 Gate FAIL이 아니다. -->

### R1. Day One — 일기 타임라인 · 작성 화면

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: Home(최근 기록), Write
- 무드: 차분함
- 가져올 것: 날짜 + 사진 썸네일 + 본문 첫 줄 미리보기로 된 최근 기록 목록. 작성 화면은 상단 날짜·사진, 아래 넓은 본문 입력으로 구성하고 저장 버튼 없이 자동 저장함.
- 피할 것: 연속 기록일(streak) 배지와 "On this day" 알림 문구의 독촉 톤. 스트릭·공백 일수를 쓰지 않는다는 PRD 6.3·7에 어긋남.

### R2. Apple 저널(Journal) — 추천 소재(Journaling Suggestions)

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: Home(오늘 기록하기 · 기록 시작 선택), Write(질문/소재)
- 무드: 개인적
- 가져올 것: 오늘 찍은 사진·활동을 카드로 보여주고 하나를 고르면 그 기록을 소재로 작성을 시작하는 흐름. 짧은 성찰 질문(prompt)을 본문 위에 두고, 답을 대신 채우지 않음.
- 피할 것: 추천 카드가 너무 많아 선택 부담이 커지는 구성. 또 질문 대신 문장 예시를 채워 넣는 방식은 AI 대필 금지(PRD 6.5)에 어긋남.

### R3. 카카오톡 — 첨부 메뉴(앨범 · 카메라 · 파일)

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: Home(기록 시작 시 사진 / 대화 캡처 / OCR / 바로 쓰기 선택)
- 무드: 신뢰
- 가져올 것: 아이콘 + 라벨이 짝지어진 입력 소스 선택 바텀시트. 선택지 4개를 한 번에 보여주고 한 번 탭으로 해당 흐름에 진입함.
- 피할 것: 아이콘만 있고 라벨이 없는 버튼. 스크린리더 이름과 색에 의존하지 않는 표현이 필요함(design-base 5).

### R4. 카카오톡 — 채팅방 말풍선

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: Write(대화 캡처용 Conversation UI)
- 무드: 개인적
- 가져올 것: 좌/우 말풍선으로 화자를 나누는 익숙한 구조. 말풍선마다 영어 입력칸을 붙여 "각 말을 영어로 직접 작성"하는 흐름에 활용함.
- 피할 것: 상대 말을 영어로 자동 번역하거나 답장 추천 문장을 제시하는 기능. AI 대필 금지(PRD 6.5), "중립적인 말풍선 작성 UI"(PRD 4 시나리오 B)에 어긋남.

### R5. Google 렌즈 — 텍스트 인식 · 선택

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: Home(OCR · 대화 캡처 진입), Write
- 무드: 신뢰
- 가져올 것: 인식된 텍스트 영역을 이미지 위에 표시하고 사용자가 쓸 부분만 골라 확인하는 단계. 인식 결과를 사용자가 확인한 뒤 작성으로 넘어감.
- 피할 것: 인식 직후 바로 "번역" 결과를 띄우는 흐름. 영어 답을 미리 주게 되어 PRD 6.5·7에 어긋남.

### R6. Grammarly — 교정 제안 카드

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: Review(수정 단위별 교정 제안과 이유, [반영] / [내 표현 유지])
- 무드: 신뢰
- 가져올 것: 수정 하나당 카드 하나로 "기존 표현 → 제안 표현 + 짧은 이유"를 보여주고, 카드마다 수락/무시를 따로 고르는 구조.
- 피할 것: "Accept all" 일괄 반영, 성과 점수, 문서 전체 AI Rewrite 버튼. 사용자 선택권·자동 Rewrite 금지·점수 금지(PRD 6.2·7)에 어긋남.

### R7. Google Docs — 제안 모드(Suggesting)

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: Review(사용자 원문 보존)
- 무드: 담백
- 가져올 것: 원문을 지우지 않고 삭제는 취소선, 추가는 밑줄로 겹쳐 보여주는 방식. 수락 전까지 원문이 그대로 남음. 색과 선 모양을 함께 써서 색에만 의존하지 않음.
- 피할 것: 색만으로 추가/삭제를 구분하는 표시(design-base 2·5). 제안이 원문을 덮어 원문을 읽기 어려워지는 밀도(PRD 6.1).

### R8. Google 포토 — 추억(Memories) 카드

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: Home(Memory Comeback Card)
- 무드: 개인적
- 가져올 것: 과거 사진 한 장 + 날짜를 크게 보여주는 카드로 과거 경험을 불러오는 입구. 앱을 연 시점에 하나만 제시함.
- 피할 것: 자동 재생 슬라이드쇼, 음악, 축하 연출. 과도한 축하 연출 금지(PRD 6.4·7)에 어긋남. 카드에 정답 영어 표현이 보이면 안 됨(PRD 3 RECALL).

### R9. Readwise — Daily Review

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: Home(Memory Comeback), RECALL 흐름
- 무드: 차분함
- 가져올 것: 예전에 저장한 것을 한 장씩 다시 꺼내 보여주는 카드 흐름. 한 번에 적은 수만 보여줌.
- 피할 것: "오늘 N개 남음" 같은 남은 개수, 연속 복습일 표시. 미완료 개수·스트릭 금지, 밀린 과제를 쌓지 않는다는 원칙(PRD 3 RECALL·6.3·7)에 어긋남.

### R10. Kindle — 단어장(Vocabulary Builder)

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: My English(저장한 표현)
- 무드: 담백
- 가져올 것: 저장한 단어마다 처음 만난 원문 문장(용례)을 함께 보여주는 구조. "처음 배움"의 근거를 사용자의 실제 원문으로 남기는 방식과 맞음.
- 피할 것: "Learning / Mastered" 같은 숙련도 단계 구분과 플래시카드 정답 판정. 숙련도 단계·정답 판정 금지(PRD 3 RECALL·7)에 어긋남.

### R11. Anki — 덱 목록

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: My English(저장한 표현 · 스스로 다시 사용한 표현 목록)
- 무드: 담백
- 가져올 것: 장식 없이 텍스트 위주로 된 목록 밀도와 빠른 탐색성.
- 피할 것: 덱마다 쌓이는 "Due" 숫자, 통계 그래프, 진행률. 미완료 개수·진행률 금지(PRD 6.3·6.4·7)에 어긋남. 달력 기준 복습 일정도 PRD 3 RECALL(앱을 연 시점 기준)과 다름.

### R12. 쿠팡 — 배송 조회 타임라인

- 링크: 미확인 (UIbowl 미검색)
- 대응 화면: My English(Expression Journey)
- 무드: 신뢰
- 가져올 것: 단계 이름 + 날짜가 세로로 이어지는 사실 기록형 타임라인. "처음 씀 → 교정 → 떠올림 → 스스로 씀"을 날짜와 근거로 보여주는 데 대응함.
- 피할 것: 전체 단계 대비 현재 위치를 보여주는 진행률 바, 도착 예정 같은 목표 압박 표현. 진행률 금지, 성취는 사실로만(PRD 6.4·7).

## 반영 요소

### RP-1. 기록 소스 선택은 아이콘+라벨 4개 선택지(사진 / 대화 캡처 / OCR / 바로 쓰기)를 한 번에 보여주는 바텀시트로 진입한다

- 근거 레퍼런스: R2, R3, R5
- PRD 연결: PRD 3 MY LIFE, 5 Home(기록 시작 시 사진 / 대화 캡처 / OCR / 바로 쓰기 중 선택)

### RP-2. Write는 소재(사진·질문)를 위에, 넓은 영어 입력칸을 아래에 두고 자동 저장한다. 질문만 두고 예시 문장은 두지 않는다

- 근거 레퍼런스: R1, R2
- PRD 연결: PRD 3 EXPRESS, 5 Write, 6.5 AI 대필 금지

### RP-3. 대화 캡처는 좌/우 말풍선에 말마다 영어 입력칸을 붙인 중립 작성 UI로 제공하고, 번역·답장 추천은 두지 않는다

- 근거 레퍼런스: R4, R5
- PRD 연결: PRD 4 시나리오 B, 5 Write(Conversation UI)

### RP-4. Review는 원문을 지우지 않고 겹쳐 표시하며, 수정마다 카드 하나("내 표현 → 자연스러운 표현 → 이유" + [반영]/[내 표현 유지])로 따로 선택한다. 일괄 반영은 두지 않는다

- 근거 레퍼런스: R6, R7
- PRD 연결: PRD 3 CORRECT, 5 Review, 6.1 원문 보존, 6.2 사용자 선택권

### RP-5. Memory Comeback은 앱을 연 시점에 과거 사진+날짜+한국어 단서 카드 하나만 보여주고, 남은 개수·연출·정답 노출은 두지 않는다

- 근거 레퍼런스: R8, R9
- PRD 연결: PRD 3 RECALL, 4 시나리오 C, 5 Home(Memory Comeback Card), 6.3 중단 존중

### RP-6. My English는 표현마다 처음 쓴 원문을 붙인 담백한 목록과, 단계 이름+날짜로 된 세로 타임라인(Expression Journey)으로 구성하고 숙련도·진행률은 두지 않는다

- 근거 레퍼런스: R10, R11, R12
- PRD 연결: PRD 3 REUSE, 5 My English(Expression Journey), 6.4 성취는 사실로 보여준다
