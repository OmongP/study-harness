# PRD — 영어가 내 것이 되는 일기

> **영어를 고쳐주는 일기는 많습니다. 우리는 고친 영어가 내 것이 될 때까지 기억합니다.**

## 1. 한 줄 정의

영어를 여러 번 다시 시작해온 성인이 자신의 실제 하루를 영어로 직접 표현하고, 교정받은 표현을 다시 떠올리고 스스로 재사용할 때까지 연결해 **'내 영어'로 만드는 서비스**다.

사진·대화 캡처·손글씨 등 실제 생활의 기록을 영어 학습의 소재로 활용한다.

## 2. 주요 사용자

### 영어 공부를 다시 시작하고 싶은 성인 직장인

- 업무와 여행에서 영어가 필요하지만 교재나 강의를 꾸준히 이어가기 어렵다.
- `시작 → 검색 → 이해 → 잊음 → 중단 → 다시 시작`을 반복하는 데 지쳐 있다.
- 영어 앱에서 교정을 받아도 실제로 그 표현을 쓸 수 있게 되었는지 확인하기 어렵다.
- 시험보다 자신의 실제 생활에서 필요한 영어를 조금씩 쌓고 싶다.
- 매일 공부하지 못하더라도 쉬었다가 다시 돌아와 이어갈 수 있기를 원한다.

## 3. 핵심 학습 구조

**MY LIFE → EXPRESS → CORRECT → RECALL → REUSE**

### MY LIFE — 실제 하루에서 시작

사용자가 빈 화면에서 억지로 일기 소재를 생각하지 않아도 되도록 실제 생활의 기록을 영어 학습의 입구로 활용한다.

- 오늘 찍은 사진 또는 갤러리 사진
- 카카오톡 등 메신저 대화 캡처
- 손글씨/OCR
- 기록 없이 바로 쓰기

사진을 선택하면 AI가 영어로 표현해볼 수 있는 **질문이나 소재**를 제안할 수 있다.

대화 캡처를 선택하면 OCR로 대화 내용을 읽고, 오늘 나눈 대화를 영어로 다시 표현할 수 있는 **말풍선 형태의 작성 UI**를 제공할 수 있다.

AI는 사용자가 그대로 답으로 사용할 수 있는 완성 영어 문장, 일기 본문, 대화 답변 또는 모범 답안을 대신 작성하지 않는다.

### EXPRESS — 직접 표현

사용자가 자신의 경험과 생각을 영어로 직접 작성한다.

AI 질문은 사용자가 경험을 떠올리기 위한 prompt 역할만 하며, 작성할 영어 답을 미리 제공하지 않는다.

### CORRECT — 이유를 이해하며 교정

사용자가 작성한 원문을 보존한 상태에서 필요한 부분만 최소한으로 교정한다.

각 수정은 다음 구조로 보여준다.

`내 표현 → 자연스러운 표현 → 수정 이유`

사용자는 각 제안에 대해 **[반영] / [내 표현 유지]**를 직접 선택한다.

교정 후 다시 사용해보고 싶은 구 단위 표현을 추적 표현으로 저장할 수 있다.

### RECALL — 내 경험으로 다시 떠올리기

저장 후 일정 시간이 지난 뒤 사용자가 다시 앱을 열면 과거 사진이나 경험, 한국어 단서를 이용해 당시 하고 싶었던 말을 다시 떠올리게 한다.

- 점수나 정답 판정을 사용하지 않는다.
- 회상 단서에 정답이 되는 영어 표현을 미리 노출하지 않는다.
- 필요하면 다른 상황에 같은 표현을 써보는 전이 단서를 제공할 수 있다.
- 전이 단서를 보고 작성한 답은 자연스러운 REUSE로 인정하지 않는다.

일정은 달력이 아니라 앱을 다시 연 시점을 기준으로 하며, 쉬었다고 밀린 과제를 쌓지 않는다.

### REUSE — 새 상황에서 스스로 사용

사용자가 이후 새로운 일기에서 이전에 배운 표현을 **힌트 없이, 올바르게 직접 사용했을 때** 앱이 이를 알아차린다.

REUSE가 일어나야 학습이 완료된 것으로 본다.

예:

- 9.28 처음 씀
- 교정
- 10.2 떠올림
- 10.14 새로운 일기에서 스스로 씀

이 기록은 Expression Journey에 사실과 날짜 중심으로 남긴다.

## 4. 핵심 사용자 시나리오

### 시나리오 A — 사진에서 영어일기 시작

1. 사용자가 회식 사진을 선택한다.
2. AI 질문을 참고해 `I drink with my company people yesterday.`처럼 직접 영어를 작성한다.
3. 사용자가 자신의 원문과 교정 제안, 이유를 확인하고 반영 여부를 선택한다.
4. 교정 후 `have drinks with` 같은 표현을 추적 표현으로 저장한다.

### 시나리오 B — 대화 캡처에서 시작

1. 사용자가 오늘 지인과 나눈 메신저 대화 캡처를 선택한다.
2. OCR로 대화 내용을 읽고 서비스가 중립적인 말풍선 작성 UI를 제공한다.
3. 사용자가 실제 대화를 떠올리며 각 말을 영어로 직접 작성한다.
4. 작성한 영어만 Review에서 교정받고 필요한 표현을 저장한다.

### 시나리오 C — Memory Comeback

1. 사용자가 며칠 뒤 앱에 돌아온다.
2. Home에 과거 사진이나 경험과 한국어 단서가 표시된다.
3. 사용자가 당시 표현을 영어로 다시 떠올려 작성한다.
4. 점수 없이 이전에 자신이 쓴 표현을 확인하고, 필요하면 다른 상황에 적용해본다.

### 시나리오 D — Reuse

1. 사용자가 이후 새로운 일기에 이전에 배운 표현을 힌트 없이 다시 쓴다.
2. 앱은 사용자 원문을 기준으로 올바른 재사용인지 확인한다.
3. 올바른 재사용이면 처음 배운 날짜와 함께 Reuse 사실을 알려준다.
4. 사용자는 My English에서 해당 표현의 Expression Journey를 확인한다.

## 5. MVP 화면

### Home

- 오늘 기록하기
- Memory Comeback Card
- 최근 기록
- 기록 시작 시 사진 / 대화 캡처 / OCR / 바로 쓰기 중 선택

### Write

- 사진 또는 기록을 바탕으로 한 질문/소재
- 영어 직접 작성
- 대화 캡처의 경우 Conversation UI 사용 가능
- 자동 저장
- 작성 중 추적 표현 힌트는 제공하지 않음

### Review

- 사용자 원문 보존
- 수정 단위별 교정 제안과 이유
- [반영] / [내 표현 유지]
- Reuse 감지 및 Reuse Notice
- 추적 표현 저장

### My English

- 저장한 표현
- 스스로 다시 사용한 표현
- Expression Journey
- 처음 배움 → 떠올림 → 스스로 씀의 날짜와 근거 확인

## 6. 반드시 지켜야 할 원칙

### 6.1 원문 보존

교정·수정 과정에서 사용자가 직접 쓴 원문을 삭제하거나 자동으로 대체하지 않는다.

목록·미리보기·회상 카드에서는 공간에 따라 원문을 축약하거나 접을 수 있지만 원문 내용 자체를 바꾸지 않는다.

### 6.2 사용자 선택권

교정은 제안으로 제공하고 반영 여부는 사용자가 직접 결정한다.

### 6.3 중단 존중

쉬었다 돌아오는 것을 정상적인 사용 패턴으로 본다.

스트릭, 공백 일수, 미완료 개수, 독촉 등 중단을 실패로 느끼게 하는 장치를 사용하지 않는다.

### 6.4 성취는 사실로 보여준다

점수·등급·숙련도 단계·진행률·과도한 축하 연출 대신 실제 발생한 기록과 날짜로 성장을 보여준다.

### 6.5 AI 대필 금지

AI는 사용자가 자신의 영어를 직접 만들어야 하는 영역에서 완성된 답변, 일기 본문, 대화 답변 또는 모범 예문을 대신 작성하지 않는다.

사진·대화 기록을 바탕으로 사용자의 경험을 떠올리게 하는 **영어 질문 생성은 허용**한다.

회상·전이 단계에서는 정답이 되는 영어 표현이나 완성 문장을 미리 노출하지 않는다.

## 7. 하지 않을 것

- 사용자의 영어를 AI가 자동 Rewrite하지 않는다.
- 작성 중 추적 표현을 힌트로 노출하지 않는다.
- 스트릭, 공백 일수, 점수, 등급, 숙련도 단계, 진행률 바, 미완료 표현 개수를 사용하지 않는다.
- 공개 피드·팔로우 등 SNS형 커뮤니티 기능을 만들지 않는다.
- 캐릭터·마스코트·과도한 이모지·축하 연출을 중심으로 학습 동기를 설계하지 않는다.

## 8. 차별화 포인트

사진·OCR·AI 교정 자체를 차별점으로 보지 않는다. 차별화는 **교정 이후의 학습 메커니즘**에서 만든다.

- **Life as Material** — 사용자의 실제 사진과 대화를 영어 학습의 소재로 활용한다.
- **Memory Comeback** — 일반 예문이 아니라 사용자의 과거 경험을 단서로 배운 영어를 다시 떠올린다.
- **Reuse Detection** — 배운 표현을 새로운 상황에서 사용자가 스스로 다시 사용했는지 감지한다.
- **Expression Journey** — 처음 씀 → 교정 → 회상 → 스스로 씀의 과정을 날짜와 근거로 기록한다.
- **Pause Is Not Failure** — 매일 하지 않아도 다시 돌아와 이어갈 수 있도록 설계한다.

## 9. 성공 기준

핵심 질문은 다음과 같다.

> **고친 영어가 실제로 사용자의 것이 되었는가?**

핵심 지표는 추적 표현이 이후 새로운 일기 원문에서 사용자의 힌트 없는 올바른 사용으로 이어지는 **Reuse율**이다.

보조적으로 다음을 확인한다.

- 사용자당 '내 것이 된 표현' 수
- 일정 기간 쉬었다가 다시 돌아오는 Return Rate
- Memory Comeback 참여
- Recall 이후 Reuse 전환
- Reuse 오탐률

사용자에게는 학습 압박을 줄 수 있는 내부 지표를 노출하지 않는다.

## 10. MVP 범위와 이후 검토

### MVP

- 실제 생활 기록을 활용한 작성 진입
- 영어 직접 작성
- 원문 보존형 교정
- 수정 이유 제공 및 사용자 선택
- 추적 표현 저장
- Memory Comeback
- Reuse Detection
- Expression Journey

### 이후 검토

- 음성 입력
- 한국어 문장 → 영어 표현 유도
- Personal English Profile
- 표현 패턴 확장

커뮤니티·공개 피드는 현재 계획하지 않는다.
