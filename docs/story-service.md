# story-service — 서비스 맥락 (R1-A)

> 출처: docs/prd.md 만 사용. PRD에 없는 내용은 추가하지 않는다.
> 용도: 유저스토리 = 하네스가 만드는 프로토타입의 범위 / 어기면 안 되는 것 = 판정 기준(R5 게이트). 작업 흐름(story-work.md)의 재료로 섞지 않는다.

## 서비스 사용자

영어 공부를 다시 시작하고 싶은 성인 직장인 (PRD §2 표현 그대로)

## 유저스토리

| # | 서비스 사용자 | 무엇을 | 한다 | PRD 근거 |
|---|---|---|---|---|
| US1 | 영어 공부를 다시 시작하고 싶은 성인 직장인 | 오늘의 사진·메신저 대화 캡처·손글씨 중 하나(또는 기록 없이)로 | 영어일기를 시작한다 | §3 MY LIFE, §5 Home |
| US2 | 사용자 | 완성 문장이 아닌 AI 질문만 참고해 자기 경험을 | 영어로 직접 쓴다 | §3 EXPRESS, 시나리오 A-2 |
| US3 | 사용자 | 원문이 보존된 상태에서 `내 표현 → 자연스러운 표현 → 수정 이유`를 보고 제안마다 | [반영]/[내 표현 유지]를 고르고, 다시 쓰고 싶은 구 표현을 저장한다 | §3 CORRECT, §5 Review |
| US4 | 쉬었다 돌아온 사용자 | 정답 영어 없이 과거 사진·경험·한국어 단서만 보고 | 당시 하고 싶었던 말을 영어로 다시 떠올린다 | §3 RECALL, 시나리오 C |
| US5 | 사용자 | 새 일기에서 배운 표현을 힌트 없이 올바르게 쓰면 | 그 사실을 날짜와 함께 Expression Journey에서 확인한다 | §3 REUSE, 시나리오 D, §5 My English |

## 어기면 안 되는 것 (판정 기준)

| # | 어기면 안 되는 것 | PRD 원문 근거 |
|---|---|---|
| N1 | AI 대필 금지 — 사용자가 직접 써야 하는 영역(Write, 대화 말풍선, 회상·전이)에 완성 영어 문장·일기 본문·대화 답변·모범 답안·정답 표현을 노출하지 않는다. 경험을 떠올리게 하는 영어 **질문**만 허용. | §6.5, §3 MY LIFE, §7 |
| N2 | 원문 보존 — 교정·수정 과정에서 사용자 원문을 삭제하거나 자동 대체하지 않는다. 목록·미리보기·회상 카드의 축약/접기만 허용하며 내용 자체는 바꾸지 않는다. | §6.1, §7 |

## R5 게이트 후보로 넘기는 PRD 금지 조항

- §6.3 중단 존중 — 스트릭, 공백 일수, 미완료 개수, 독촉 금지
- §6.4 성취는 사실로 — 점수, 등급, 숙련도 단계, 진행률, 과도한 축하 연출 금지
- §7 — 작성 중 추적 표현 힌트 금지, SNS형 커뮤니티 금지, 캐릭터·마스코트·과도한 이모지 중심 동기 설계 금지

## PRD 미정의 (R5에서 결정)

- RECALL "저장 후 일정 시간이 지난 뒤"의 구체 기간
- REUSE "올바르게 직접 사용"의 판정 기준
