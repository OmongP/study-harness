# design-base.md — 공통 디자인 기준 (고정)

> 어떤 서비스 PRD에도 적용하는 디자인 기준이다. 사람과 에이전트가 읽는다.
> 출처: 영어일기 `docs/design.md`에서 서비스에 종속되지 않는 기준만 분리했다 (2026-09-29). 원본은 수정하지 않았다.
> 이 중 기계가 셀 수 있는 규칙은 `harness/rules-base.yaml`에 있다. 수치를 바꾸면 두 파일을 함께 고친다.
> 팔레트 값·폰트·서비스 전용 컴포넌트·서비스 금지 사항은 실행별 `runs/<run-id>/3-design/design.md`에서 정한다.
> HTML로 어떻게 구현하는지는 `harness/guides/html-screen-guide.md`에 있다.

## 1. 기준 화면

| 항목 | 값 |
|---|---|
| 기준 프레임 | `390 × 844` (키스크린·전체 화면 모두) |
| 최소 폭 | `360px` — 가로 스크롤 없이 줄바꿈 |
| 플랫폼 | 모바일 우선. 태블릿·데스크톱 레이아웃은 범위 밖 |

## 2. 색 (규칙만 — 값은 서비스별 design.md)

- 서비스별 design.md의 색 토큰 목록에 있는 값만 쓴다. 목록 밖의 색 값 = 하드코딩 = 위반.
- 토큰은 정해진 역할 안에서만 쓴다. 장식용 색, 그라데이션, 임의 상태색을 추가하지 않는다.
- 색만으로 의미를 전달하지 않는다. 텍스트·밑줄·아이콘·구조를 함께 쓴다.
- 사용자 사진 같은 콘텐츠 이미지는 색 규칙 대상이 아니다.

## 3. 타이포그래피 (규칙만 — 폰트·스케일은 서비스별 design.md)

- 읽는 텍스트는 16px 이상.
- 16px 미만은 두 역할에만 허용: `caption` 13px (날짜·메타 정보), `label` 14px (짧은 컨트롤 라벨).
- 시스템 글자 크기 200% 확대에서도 정보가 잘리지 않고 줄바꿈된다. 정보 텍스트를 줄 수로 고정하지 않는다.

## 4. 레이아웃 · 모양

| 항목 | 허용 값 |
|---|---|
| 간격 단위 | 4px 기반 |
| 간격 (padding · gap) | `4 / 8 / 12 / 16 / 20 / 24 / 32` |
| 화면 좌우 여백 | `20` |
| 모서리 (radius) | `0 / 8 / 12 / 16 / 999(pill)` — `0`은 모서리 없는 요소 (2026-09-29 승인) |

- 기존 토큰으로 되는 곳에 임의 값을 만들지 않는다.

## 5. 터치 영역 · 접근성

- 모든 인터랙티브 요소의 탭 영역은 `44 × 44px` 이상. 보이는 모양은 작아도 되지만, 보이지 않는 탭 영역이 44 × 44px 이상이어야 한다.
- 글자·배경 대비 `4.5 : 1` 이상.
- 상태를 색만으로 전달하지 않는다.
- 인터랙티브 요소에는 스크린리더용 의미 있는 이름이 있다.
